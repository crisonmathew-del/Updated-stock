# Breakout web

Next.js 16 (App Router) frontend. See the repo root `CLAUDE.md` for conventions and commands.

```bash
pnpm install
pnpm dev          # http://localhost:3000; expects the API on http://localhost:8000 (or API_URL)
pnpm lint && pnpm format:check && pnpm typecheck && pnpm test && pnpm build
```
